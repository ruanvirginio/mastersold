# Scripts pra dissertação de mestrado

- Transformadores utilizados: `T21a`, `T22a` e `T70a`;
- Forecast recursivo de séries temporais;
- Modelos usados: `LGBM`, `XGBoost` e `GradientBoosting`;
- Calcula e imprime MAPE/RMSE/R2 por transformador/modelo.

Univariate: `RF_MM_UV_HPT.py`
Multivariate: `RF_MM_MV_HPT.py`

Base usada por padrão:

- `bases_tratadas/daily_peak_transformers_dataset.csv`
